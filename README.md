# 🚀 Java მისია: მასივები და ციკლები (Arrays & Loops)

მოგესალმებით, მომავალო დეველოპერებო! დღეს ჩვენ ვისწავლით, როგორ შევინახოთ ბევრი მონაცემი ერთად და როგორ ვაიძულოთ კომპიუტერი, რომ ჩვენ მაგივრად იმუშაოს ციკლების (`for` loop) დახმარებით.

ქვემოთ მოცემულია 3 საინტერესო გამოწვევა. ყურადღებით წაიკითხეთ ინსტრუქციები და შეასრულეთ კოდში!

---

## 🎒 დავალება 1: თამაშის ზურგჩანთა (InventorySearch.java)

**🔹 სიტუაცია:** წარმოიდგინე, რომ ქმნი RPG თამაშს. შენს პერსონაჟს ზურგჩანთაში უდევს სხვადასხვა ნივთი. ჩვენი მიზანია, სათითაოდ შევამოწმოთ ყველა ნივთი და თუ ზურგჩანთაში **გასაღებს ("Key")** ვიპოვით, გავაღოთ საიდუმლო კარი!

**🔹 შენი ამოცანა:**

1. შექმენი `String`-ების მასივი, სადაც ჩაწერ რამდენიმე ნივთს (მაგალითად: `"Sword"`, `"Shield"`, `"Potion"`, `"Key"`, `"Coin"`).
2. `for` ციკლის გამოყენებით სათითაოდ დაბეჭდე ზურგჩანთის ყველა ნივთი.
3. ციკლის შიგნით გამოიყენე `if` პირობა. თუ ნივთი არის `"Key"`, ეკრანზე დამატებით დამიბეჭდე: **"გასაღები ნაპოვნია! საიდუმლო კარი იღება... 🗝️"**.

> 💡 **მინიშნება:** Java-ში ტექსტების ერთმანეთთან შესადარებლად იყენებენ `.equals()` ბრძანებას და არა `==`-ს. მაგალითად: `backpack[i].equals("Key")`

## 🦸‍♂️ დავალება 2: სერვერზე მისალმების რობოტი (NameTagMaker.java)

**🔹 სიტუაცია:** შენ ხარ Minecraft-ის სერვერის ადმინისტრატორი. სერვერზე ერთდროულად ბევრი მოთამაშე შემოდის. ხელით თითოეულისთვის "გამარჯობა"-ს მიწერა დამღლელია. მოდი, ავტომატურად მივესალმოთ ყველას!

**🔹 შენი ამოცანა:**

1. შექმენი `String`-ების მასივი მოთამაშეების სახელებით (მაგალითად: `"Alex"`, `"Sam"`, `"Jordan"`, `"Luka"`).
2. `for` ციკლის დახმარებით "გადაურბინე" მთელ მასივს.
3. ეკრანზე თითოეული მოთამაშისთვის დაბეჭდე პერსონალური მისალმება, მაგალითად: **"მოგესალმებით სერვერზე, Alex! ✨"**.

---

## 🏆 დავალება 3: რეკორდების დამამხობელი (HighScoreFinder.java)

**🔹 სიტუაცია:** შენმა მეგობრებმა ითამაშეს კომპიუტერული თამაში და დააგროვეს ქულები. ეს ქულები შენახულია ციფრების მასივში. ახლა უნდა გავარკვიოთ, ვინ არის ჩემპიონი — ანუ რომელია ყველაზე დიდი ციფრი ამ მასივში!

**🔹 შენი ამოცანა:**

1. შექმენი მთელი ციფრების მასივი (`int[]`) და ჩაწერე მასში რამდენიმე მეგობრის ქულა (მაგალითად: `50, 120, 85, 90, 150, 30`).
2. ციკლის დაწყებამდე შექმენი ცვლადი `int highestScore = 0;` (აქ შევინახავთ ყველაზე დიდ ქულას).
3. `for` ციკლით შეამოწმე მასივის თითოეული ციფრი. `if` პირობით შეადარე: თუ მიმდინარე ქულა უფრო დიდია, ვიდრე `highestScore`, მაშინ `highestScore`-ში ჩაწერე ეს ახალი, უფრო დიდი ციფრი.
4. ციკლის დასრულების შემდეგ (ციკლის ფრჩხილებს გარეთ!) ეკრანზე დაბეჭდე ყველაზე მაღალი ქულა.

---

### 🔥 ოქროს წესები შეხსენებისთვის:

* მასივში ათვლა ყოველთვის იწყება **0**-დან და არა 1-დან!
* მასივის სიგრძის გასაგებად გამოიყენე `.length` (მაგალითად: `scores.length`).
* ციკლში ფრთხილად იყავი, რომ პირობა სწორად დაწერო (`i < array.length`), თორემ პროგრამა ამოაგდებს შეცდომას: `ArrayIndexOutOfBoundsException`.
